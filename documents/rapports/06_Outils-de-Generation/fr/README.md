# Outils de génération — français

> **Objet :** Outils de génération — français.


Ce dossier de langue documente les outils sans déplacer les scripts ou le logo
source. `Generer-Documents-Conception.ps1` crée les versions Word/PDF des
conceptions françaises et anglaises. `Convertir-HTML-en-Word-PDF.ps1` produit
les exports des pages HTML de cadrage, d'architecture et de gestion.

L'outil Java et le script `Protect-Report-Pdfs.ps1` sont maintenant rangés
dans `integration-tests/src/test/` avec des tests isolés sur des rapports
temporaires. Les restrictions PDF dépendent des lecteurs compatibles et ne
peuvent pas empêcher les captures d'écran, les photographies ou les logiciels
qui les ignorent. Le logo officiel reste dans le dossier
`06_Outils-de-Generation`.

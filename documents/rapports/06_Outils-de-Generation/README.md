# Generation Tools

> **Organization:** Portage Cybertech · **Project:** Mini OAuth 2.0 platform
> **Author:** Sylvose Allogo · **Email:** sylvose.allogo@yahoo.com · **Version:** 1.0.0 · **Date:** 2026-10-04
> **Purpose:** Document generation tools — PowerShell scripts for converting HTML sources to Word and PDF, and regenerating all project reports.

This directory contains the PowerShell automation scripts used to generate and export all Word and PDF deliverables across the project. It also holds the official Portage CyberTech brand asset used on report cover pages, and language-specific index files for the generation toolset.

## Scripts

### `Generer-Rapports.ps1`

Regenerates the main narrative project reports (feasibility study, Postman test reports, deliverable catalogue) by driving Microsoft Word to produce `.docx` and `.pdf` exports from their respective sources. Run from the repository root:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\documents\rapports\06_Outils-de-Generation\Generer-Rapports.ps1
```

Reports regenerated by this script include:
- `01_Cadrage/fr/etude-de-faisabilite-portage-cybertech.docx`
- `04_Tests-et-Validation/fr/rapport-tests-postman.docx`
- `04_Tests-et-Validation/fr/Rapport-des-tests-Endpoint-Postman-Env-Dev.html` and its Word/PDF exports
- `04_Tests-et-Validation/en/Postman-Endpoint-Test-Report-Dev-Environment.html` and its Word/PDF exports
- `05_Gestion-et-Livrables/fr/catalogue-livrables-ecarts.docx`

### `Convertir-HTML-en-Word-PDF.ps1`

Converts any HTML source file to Word (`.docx`) and PDF by automating Microsoft Word. Used for all deliverables that are authored in HTML and exported — architecture documents, scoping documents, test reports, management reports, and design documents. The output files are placed alongside the source HTML in the same language subdirectory.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\documents\rapports\06_Outils-de-Generation\Convertir-HTML-en-Word-PDF.ps1
```

### `Generer-Documents-Conception.ps1`

Regenerates the detailed design documents for both language editions and their Word/PDF exports from their HTML sources. Also produces Word/PDF exports of the BPMN process descriptions in `02_Architecture/`.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\documents\rapports\06_Outils-de-Generation\Generer-Documents-Conception.ps1
```

Reports regenerated by this script include:
- `03_Conception/fr/conception-detaillee-mini-plateforme-oauth2.html` and its Word/PDF exports
- `03_Conception/en/detailed-design-mini-oauth2-platform.html` and its Word/PDF exports

## Prerequisites

All three scripts require:
- **Windows** operating system
- **Microsoft Word** installed and licensed (used for `.docx` and `.pdf` export via COM automation)
- **PowerShell** with script execution allowed (`-ExecutionPolicy Bypass`)

No additional tools (Node.js, Pandoc, LaTeX, etc.) are required. The scripts operate entirely through Microsoft Word automation.

## Relationship to other deliverables

These scripts produce exports consumed by all other report directories:

| Script | Produces exports in |
|---|---|
| `Generer-Rapports.ps1` | `01_Cadrage/`, `04_Tests-et-Validation/`, `05_Gestion-et-Livrables/` |
| `Convertir-HTML-en-Word-PDF.ps1` | `01_Cadrage/`, `02_Architecture/`, `03_Conception/`, `04_Tests-et-Validation/`, `05_Gestion-et-Livrables/` |
| `Generer-Documents-Conception.ps1` | `03_Conception/`, `02_Architecture/` |

The PowerDesigner model automation script (`02_Architecture/Scripts/Generate-PowerDesigner-Models.ps1`) regenerates native modeling sources and diagram images only; it is separate from the document export pipeline here.

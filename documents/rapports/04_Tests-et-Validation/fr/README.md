Les rapports français de tests sont fournis en HTML, Word et PDF :

- `rapport-tests-postman` — rapport de tests de contrat Postman.
- `rapport-tests-unitaires` — résultats historiques des tests unitaires
  Maven.
- `rapport-tests-integration` — résultats historiques des tests d'intégration
  et de contrat Maven.

Les résultats horodatés ne représentent que leur exécution d'origine et ne
confirment pas l'état actuel du dépôt. Les collections, environnements,
scripts et captures restent dans `../Postman/`; les résultats bruts restent
dans `../Rapports-historiques/`. Les profils Int et Prod sont des simulations
localhost et ne certifient pas des environnements distants.

Les rapports anglais sont dans `../en/`.

Le rapport consolidé des endpoints Postman pour l’environnement Dev est
`Rapport-des-tests-Endpoint-Postman-Env-Dev` (HTML, Word et PDF); la version
anglaise est dans `../en/Postman-Endpoint-Test-Report-Dev-Environment`.

L’historique structuré des besoins et des décisions est fourni dans
`Historique-des-demandes-et-reponses-Mini-plateforme-OAuth2.docx`. Son HTML
source est disponible dans ce dossier et l’édition anglaise dans `../en/`.
La synthèse corrigée du fichier de demandes est conservée dans
`../../Historique-structure-des-demandes-et-reponses-OAuth2.txt`. Le document
source reçu est archivé séparément sous
`../../Historique-source-recu-2026-10-04.txt`.

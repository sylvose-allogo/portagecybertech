Le dossier contient la conception de la mini-plateforme OAuth 2.0 en HTML,
Word et PDF. Il décrit le contexte, les décisions, les composants, les
contrats JWT/JWKS, les flux RFC 8693, les contrôles de sécurité, le déploiement
de démonstration et les vérifications proposées.

Les éléments effectivement observés dans le dépôt sont différenciés des
recommandations d'exploitation. Les sources PlantUML éditables sont dans
`..\Diagrammes-PlantUML\`; les modèles BPMN, UML, EAM, DMN et BPEL restent dans
`..\..\02_Architecture\`.
